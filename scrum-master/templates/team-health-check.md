# Team health check: <team>, <date>

A self-assessment the team runs every two or three months, adapted from the squad health check format Spotify published. Each person rates each area **green** (good), **amber** (some problems), or **red** (a real problem), and says whether it's improving, stable, or getting worse. Then the team discusses the results and picks one area to work on.

Keep the results within the team. They're for the team's own improvement, not for comparing teams.

| Area | Green looks like | Red looks like | Votes (G / A / R) | Trend |
|---|---|---|---|---|
| **Clear goals** | We know what we're working toward and why | We don't know why we're doing this work | | |
| **Value delivered** | Our work makes a visible difference to our users | We build things nobody uses | | |
| **Pace** | We work at a sustainable pace | We're always rushing or always firefighting | | |
| **Interrupts** | Unplanned work is manageable and shrinking | Interrupts swamp planned work | | |
| **On-call** | On-call is fair and rarely wakes anyone | On-call is exhausting and unfair | | |
| **Quality and tech health** | Our systems are in good shape and easy to change | Our systems are fragile and scary to touch | | |
| **Easy to release** | Releasing is routine and low-risk | Releasing is painful and risky | | |
| **Support from outside** | We get what we need from other teams quickly | We're always waiting on someone | | |
| **Learning** | We learn new things and have time to | We never have time to learn | | |
| **Safety to speak up** | We can raise problems and disagree without fear | People keep problems to themselves | | |
| **Teamwork** | We help each other and work well together | We work as individuals | | |
| **Fun** | We enjoy working together | Work is a slog | | |
